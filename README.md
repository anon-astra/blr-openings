# BLR Openings

New food & drink openings in Bangalore, refreshed daily at 8am IST. Every entry links to its source.

- `data.json`: posts (slug, name, type, area, opened as YYYY-MM-DD, note, body paragraphs, sources, optional featured) and `updated` ("YYYY-MM-DD HH:MM", IST).
- `build.tov`: renders data.json into index.html. Run `tov run build.tov`, then copy dist/index.html to index.html.

Built with [Tov](https://github.com/richiemcilroy/Tov).
